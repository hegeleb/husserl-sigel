# Зиглы Гуссерля · словарь стенографии

Статический исследовательский словарь с несколькими конволютами.

- **Словарь**: поиск по слову, буквальному каркасу и описанию; фильтры конволюта, листа, графики, семейства, морфемы, слоя и типа.
- **Графические формы**: подборки по признакам и семействам, морфемные серии, пары и омографы.
- **Туториал**: алфавит и выдержки из «Записки», открытые чтения, принципы идиолекта.

Первый корпус — **A V 21**. **B I 13** подготовлен для пополнения; отсутствие карточек обозначено явно. Подборки по морфемам опираются на чтение слова, а не утверждают наличие отдельного графического знака.

Сканы A V 21: **Husserl-Archiv, KU Leuven**, [IIIF-манифест](https://lib.is/IE12988110/manifest), CC BY-SA согласно описанию исходного корпуса. При повторном использовании сохраняйте атрибуцию и лицензию. Печатный источник: Husserliana XLII, *Grenzprobleme der Phänomenologie*, hrsg. R. Sowa / T. Vongehr, 2014.

Школьные таблицы туториала: F. X. Gabelsberger, *Anleitung zur deutschen Redezeichenkunst*, 1850; [экземпляр BSB/MDZ bsb10858241](https://www.digitale-sammlungen.de/de/view/bsb10858241). Учебные выдержки — из локальной «Записки»; личный журнал обучения не экспортируется.

Постоянные ссылки используют ID карточки; параметры выборки сохраняются в адресе страницы. Старые ссылки `#w=…`, `#bl=…`, `#parts` продолжают открываться.

Сборка из рабочего каталога Gabelsberger: `python3 Woerterbuch/tools/export/publish.py --thumbs`. Эта команда только создаёт локальный сайт. Изменения на GitHub отправляются отдельно.
