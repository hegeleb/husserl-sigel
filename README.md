# Указатель гуссерлевских зиглов и сокращений (A V 21)

Статический сайт: `index.html` + папка `img/` с вырезками из сканов.

**Материал.** Конволют A V 21 «Ethisches Leben. Theologie — Wissenschaft» (1924–1927),
Husserl-Archiv, KU Leuven. Сканы доступны по IIIF: https://lib.is/IE12988110/manifest,
лицензия **CC BY-SA**. При повторном использовании вырезок сохраняйте атрибуцию архива
и ту же лицензию.

**Печатный эталон.** Husserliana XLII. *Grenzprobleme der Phänomenologie*,
hrsg. R. Sowa / T. Vongehr, Springer 2014.

**Обновление.** Указатель ведётся в markdown; сайт пересобирается скриптами
`tools/export/` и заливается целиком.
